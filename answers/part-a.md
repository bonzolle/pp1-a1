# Del A: Regler för ett resekort

## Regler som borde gälla

1. Man ska inte direkt kunna gå på variabeln och ändra värdet. man kan göra balance privat
2. Inte tillåtet att gå minus på balans
3. Skydd mot travelcard id, gör att objekter faattar beslutet själv

## Varför skyddar inte dataclassen mot felen?
Man skyddar inte variablerna. man vill att själva klassen är public men att värdena lagrade i objektet inte kan ändras.
det ska alltså bara vara själva klassens metoder som ska kunna ändra på värdena

# Inlämning 1: Reskassa

Startkod för inlämning 1 i Programmeringsparadigmer 1. Hela uppgiftsbeskrivningen finns i Canvas.

Projektet är ett Maven-projekt. Öppna mappen i IntelliJ IDEA, så känns det igen automatiskt.

| Var | Innehåll |
|---|---|
| `python/` | Python-skriptet för del A |
| `src/main/java/` | `Card` och programmen `B1`–`B4` för del B. Förutsäg utskriften **innan** du kör dem. |
| `src/main/java/` | Modellklassen `Zone`. Här skapar du `TravelCard`, `Trip` och `Main` (del C). |
| `src/test/java/` | Plats för tester (används inte i den här uppgiften) |
| `uml/` | Ditt klassdiagram från Astah (`.asta`) eller Mermaid (`.mmd`), och en exporterad bild |
| `answers/` | Dina svar på del A, B och D |

Gör en commit efter varje steg i del C.
